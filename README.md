# Bakery Management System

## Project Overview
The Bakery Management System is a web-based application developed to manage bakery products, categories, stock, suppliers, and customer orders.

## Features
- Product management
- Category management
- Stock management
- Supplier management
- User login and account management
- Bakery product maintenance

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap (if used in the project)

## Project Structure
- `index.php` – Main entry page
- `login.php` – User login
- `home.php` – Home page
- `manage_product.php` – Product management
- `manage_category.php` – Category management
- `manage_stock.php` – Stock management
- `manage_supplier.php` – Supplier management
- `DBConnection.php` – Database connection

## How to Run
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs`.
3. Start Apache and MySQL.
4. Import the project database using phpMyAdmin.
5. Configure the database connection.
6. Open the project through localhost in your browser.
